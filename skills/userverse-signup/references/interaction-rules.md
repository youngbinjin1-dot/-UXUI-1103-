# 입력·상태 규칙

## 문구 (해요체)
| 위치 | 문구 |
|---|---|
| 로그인 | ★ PLAYER LOGIN · 다시 만나서 / 반가워요 · 유저버스 계정으로 로그인해 주세요. |
| 회원가입 | ★ NEW PLAYER · 계정 만들기 · 몇 가지만 입력하면 / 바로 시작할 수 있어요. |
| 재가입 | ★ WELCOME BACK · 다시 오셨군요! · 다시 만나서 정말 반가워요. · 버튼 "다시 시작하기" |
| 플레이어 정보 | ★ PROFILE SETUP · 플레이어 정보 입력 · 사용할 닉네임과 비밀번호를 / 정해 주세요. |
| 완료 | ★ STAGE CLEAR · 가입이 완료됐어요 · {닉네임}님, 유저버스에 오신 걸 환영해요! |
| 재가입 완료 | 다시 함께하게 돼서 / 기뻐요 · 그동안 잘 지내셨나요? {닉네임}님, 다시 환영해요! |

## 이메일
| 조건 | 표시 | 시점 |
|---|---|---|
| 형식 오류 | 경고 말풍선 "이메일 형식을 확인해 주세요 / 예: player@userverse.gg" + ERR | 입력을 마친 뒤(blur·Enter), 고칠 때까지 유지 |
| 이미 가입 (`sisbhjj@gmail.com`) | 카드 "당신 계정 아닌가요?" + [로그인하기](이메일 채워서 로그인 화면) + 비밀번호 찾기, CTA 비활성 | 입력 즉시 |
| 탈퇴 후 재가입 (`comeback@gmail.com`) | 환영 카드 "다시 돌아오신 걸 환영해요! 예전에 쓰던 닉네임 CometRider를 그대로 다시 쓸 수 있어요." + 상단 핑크 빛 + 환영음 | 입력 즉시 |
| 정상 | OK! + 테두리 민트 + `+10 XP` | 입력 즉시 |

## 닉네임
- 퀘스트 칩: `2~12자` · `한글·영문·숫자만` · `아무도 안 쓰는 이름` (회색 → 민트/주황)
- 입력칸 안 `n/12` 카운터 (12 초과 시 주황)
- 메시지: 공백이나 특수문자는 쓸 수 없어요 / 2자 이상 입력해 주세요(포커스 벗어난 뒤) / 12자 이하로 입력해 주세요 / 이미 사용 중인 닉네임이에요 / 멋진 닉네임이에요!
- 조합 중인 한글 자모(ㄱ, ㅏ)는 오류로 보지 않는다
- **🎲 추천 버튼**: 칸이 비어 있으면 항상 표시. 직접 입력하면 숨김, 추천으로 채운 이름이면 다시 굴릴 수 있게 유지.
  누르면 70ms 간격 9번 슬롯머신(틱음) → 멈추면 코인음 + `+10 XP`.
  조합 = 형용사(반짝이는·용감한·네온·픽셀…) + 명사(고양이·유니콘·슬라임…) + 숫자(선택), 12자 이내, 중복 제외
- 재가입이면 예전 닉네임을 미리 채우고 "예전에 쓰던 닉네임이에요. 다시 만나 반가워요!"

## 비밀번호
- 퀘스트 칩: `영문 포함` · `숫자 포함` · `8자 이상` — 채우는 대로 민트, 칸을 벗어난 뒤 미충족 항목은 주황
- 확인 칸: 일치하면 바로 OK!, 불일치 말풍선 "비밀번호가 일치하지 않아요"는 **길이만큼 다 입력했거나 칸을 벗어난 뒤**에만

## 거주 국가
- 칸(국기 + 이름 + 셰브론)을 누르면 바텀시트 "거주 국가 선택"
- 검색(한글·영문), 결과 없음 "찾는 나라가 없어요"
- 방향키 이동·Enter 선택·Esc 닫기, 배경 클릭·✕ 닫기
- 선택 시 체크음, 다른 나라로 바꾸면 `+5 XP`

## 캡차·약관
- 둘 다 기본 꺼짐, 체크 팝 + 두 음 + `+10 XP`
- 약관 문구: 만 13세 이상이며, / 유저버스 이용약관 및 / 개인정보 처리방침에 동의합니다. (약관 이름 링크색 밑줄, 의미 단위 줄바꿈)

## 게이지
- 24칸 블록. 단계 진행 + 현재 단계에서 완료한 항목 수(3개 기준)만큼 실시간으로 채움. 마지막 칸은 밝은 핑크.

## 게임 피드백 공통
| 이벤트 | 시각 | 소리 |
|---|---|---|
| hover | 테두리 한 단계 밝게 | 아주 작은 square 블립 |
| focus | 라벨 앞 `▶` 깜빡임, 테두리 핑크 | 블립 |
| 타자 | — | 아주 작은 랜덤 틱 |
| 통과 | 테두리 민트, OK!, `+10 XP` | 코인 |
| 오류 | 테두리 주황, ERR, 흔들림 | 낮은 두 음 |
| 버튼 | 누르면 2px 내려감 | 낮은 '톡' |
| 화면 전환 | 슬라이드 320ms | swoosh |
| 완료 | 컨페티, 별 둥실 | 4음 팡파르 |

사운드는 첫 클릭 뒤 시작(브라우저 정책), 상단에 켜기/끄기 버튼.
