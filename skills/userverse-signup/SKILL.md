# 유저버스형 회원가입 리디자인

원본 서비스(예: 스팀) 회원가입 스크린샷과 무드 레퍼런스 이미지를 받아
**독립된 앱 브랜드 + 디자인 md + 게임형 클릭 프로토타입 + Figma 화면**으로 만드는 절차.

완성 예시는 이 저장소에 있다.
- `index.html` — 유저버스 클릭 프로토타입
- `userverse.md` — 디자인 시스템 md
- `steam.md` — 같은 형식의 원본 브랜드 md (형식 참고용)
- `fonts/` — DOS 픽셀 폰트 서브셋 + 라이선스

## 입력
- 원본 화면 스크린샷 (로그인, 회원가입, 계정 정보, 오류 상태)
- 무드 레퍼런스 이미지 (색감·폰트·그래픽 모티프를 뽑을 이미지)
- 사용할 폰트 (예: github.com/hurss/fonts) — 없으면 레퍼런스에 맞는 무료 폰트
- 데모 값: 이미 가입된 이메일, 탈퇴 후 재가입 이메일과 예전 닉네임, 중복 닉네임

## 절차

### 1. 브랜드 분리
- 원본 서비스 이름·로고·약관명을 모두 새 앱 이름으로 바꾼다 (스팀 → 유저버스, "유저버스 이용약관").
- 원본 로고·워드마크를 그리지 않는다. 실제 로그인처럼 동작하는 페이지를 만들지 않는다(전송 없음, "데모" 표기).

### 2. 디자인 md 작성
`steam.md`와 같은 형식(frontmatter + ①~⑫)으로 쓴다. 자세한 항목은 `references/design-md-format.md`.
- 레퍼런스에서 **배경색 1 + 강조색 1**을 뽑고, 오류·성공은 강조색과 헷갈리지 않는 HUD 색만 예외로 둔다.
- 폰트·모서리·그래픽 모티프·컴포넌트 CSS·사운드·금지 규칙을 적는다.

### 3. 화면 흐름
① 로그인 → ② 회원가입 → ③ 플레이어 정보 → 완료(STAGE CLEAR)
- **로그인**: 이메일 + 비밀번호 → 로그인 버튼 → "로그인에 문제가 있나요?" → 점선 구분선 "아직 계정이 없나요?" → 회원가입(고스트)
- **회원가입**: 이메일 1회(확인 칸 없음) · 거주 국가(바텀시트 선택) · 캡차 · 나이 동의
- **플레이어 정보**: 닉네임(추천 버튼) · 비밀번호 · 비밀번호 확인
- 모든 화면 같은 골격: 상태바 → 헤더(‹ + 로고) → XP 게이지 → 제목 → 입력 → 하단 고정 CTA

### 4. 규칙 (전부 `references/interaction-rules.md`)
- 체크박스는 처음에 모두 꺼짐, 조건을 다 채워야 CTA 활성
- 이메일: 가입된 이메일 → "당신 계정 아닌가요?" 카드 / 재가입 → 환영 분위기 / 형식 오류 → 입력을 **마친 뒤** 말풍선
- 닉네임: 2~12자 · 한글·영문·숫자만 · 중복 아님 — 퀘스트 칩 + `n/12` 카운터
- 닉네임 추천(🎲) 버튼은 **칸이 비어 있으면 항상** 표시
- 비밀번호 확인 불일치는 **다 입력한 뒤**에만
- 진행도는 숫자 없이 24칸 블록 게이지
- 거주 국가는 눌러서 검색·선택하는 바텀시트

### 5. 게임형 피드백
모든 칸이 게임 HUD처럼 반응한다: 포커스 `▶` 깜빡임, 타자음, `OK!`/`ERR` 뱃지, `+10 XP`, 흔들림, 체크 팝, 완료 컨페티.
사운드는 Web Audio로 합성한 작고 짧은 8비트 소리(경박한 효과음·총소리 금지) + 끄기 버튼.

### 6. 폰트
- 웹폰트 원본이 크면(한자 포함 TTF 수 MB) `pyftsubset`으로 한글(U+AC00–D7A3)·자모·영문·기호만 남겨 WOFF로 줄인다.
- brotli가 없으면 `--flavor=woff`.
- 폰트에 없는 기호(예: ✦)는 있는 기호(★ ▶ ■)로 바꾼다.
- 채팅 미리보기용은 폰트를 base64로 HTML에 넣고, 저장소용은 `fonts/` 상대 경로로 둔다. 라이선스 파일을 함께 넣는다.

### 7. 검증 (Playwright)
- 흐름: 회원가입 → 이메일 오류 → 수정 → 캡차·동의 → 계속 → 닉네임 오류 → 추천 → 비밀번호 → 완료
- 확인: 콘솔 에러 없음, 버튼 활성/비활성, 추천 버튼 표시 조건, 말풍선 타이밍, 국가 검색·방향키·Esc
- **blur 때 오류 UI가 뜨면 레이아웃이 밀려 다른 칸 클릭이 빗나간다** → 포인터를 뗀 뒤 표시

### 8. Figma
절차와 함정은 `references/figma-notes.md`.
새 페이지에 토큰 변수 · 텍스트 스타일 · 컴포넌트(Input 상태 변형, Button, Badge, Quest Chip, Checkbox) · 상태별 화면을 만든다.

### 9. GitHub
- 사용자가 지정한 브랜치에만 올린다. 새 작업은 새 브랜치, `main`은 요청이 있을 때만.
- 배포용 프로토타입은 루트 `index.html` + `.nojekyll`.
- GitHub Pages 주소는 저장소 이름의 **대소문자 그대로** (`/-UXUI-1103-/`). 소문자로 쓰면 404.
- 얕은 clone에서 새 브랜치를 push하면 추적 설정이 빠질 수 있다 → `remote.origin.fetch`에 브랜치 refspec 추가 후 `git branch -u`.
